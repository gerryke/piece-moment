# Pieceful Moment 1.1.3 App Store Screenshot Design

Date: 2026-08-09

Language: English only

Devices: iPhone 6.9-inch and iPad 13-inch

## Decision

Ship a single product-page direction based on the existing Treatment A visual and content strategy. Do not produce or preserve an Original/Baseline alternative.

- iPhone receives a complete ten-image Treatment A set.
- iPad keeps its current ten-image set and ordering; only the existing completion-focused image at position 6 is replaced.
- The new 1.1.3 completion/share experience appears within the first four iPhone images.

This decision uses the current product-page test as directional evidence: Treatment A converted at 2.38% versus 1.74% for the Original page, a relative improvement of 36.96%. Confidence is still low, so the result is treated as a creative direction rather than a statistically final claim.

### iPhone visual rules

- All ten posters use the Treatment A design system; pages 4–10 must not fall back to the quieter Original/v8 poster style.
- Preserve the locked first three posters unless a purely technical export correction is required.
- Use real in-app UI and supplied completion exports; do not invent game mechanics or UI states.
- Page 4 is the main 1.1.3 release moment. It should clearly communicate completion and sharing while remaining legible at App Store thumbnail size.
- Use the new deep-teal 1.1.3 brand tone as the unifying accent across newly rendered pages.
- Keep headline length and hierarchy consistent with the existing Treatment A trio.
